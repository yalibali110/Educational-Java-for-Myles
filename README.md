# Educational-Java-for-Myles
Practice Java programs featuring full comment descriptions for the sake of educating my peers at the Community College of Philadelphia

The code I wrote was for the following challenges:

RainfallProgram.java
  Create a program that prompts the user to enter rainfall amounts (in inches) for 12 months of one year. Your program must utilize an array of Month objects, which each hold the month's name and the amount of rain in that month.

RockPaperScissors.java
  Create a program that plays a game of rock, paper, scissors. Your program should allow the user to enter "rock", "paper", or "scissors". The program will randomly select "rock", "paper", or "scissors". The winner is then printed.

MorseConverter.java
  Create a program that prompts the user to enter words or a phrase. Print the user's input translated into Morse code. Use periods for "dots" and hyphens for "dashes". Place one space between each "letter" printed in Morse code; Place two spaces between each "word" printed in Morse code. Uppercase and lowercase letters are treated equally.

AddressConverter.java
  Create a program that reads a text file containing mailing addresses. Write each address (street address, city, state, and zip code) as individual lines in a CSV file.
